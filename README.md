# Cosmic Voyager

A browser space opera. Rotate, thrust, dock, fight, take contracts. Crypto is the costume, not a wallet.

Single-folder HTML5: `index.html` + `game.js` + `style.css` + `assets`. No build step, no Unity, no wallets.

## Play

- **Online:** open the GitHub Pages link for this repo (Settings → Pages, or the environment URL once it is live).
- **Local:** download/clone this folder and open `index.html` in Chrome.

## Controls

| Key | Action |
|---|---|
| W / Up | Thrust |
| S / Down | Reverse burn |
| A D / Left Right | Rotate |
| Space or click | Fire |
| Q or [ ] | Cycle weapons |
| Tab | Chain special |
| Shift | Faction special |
| E | Dock / interact |
| M | Star chart |
| Esc | Pause |
| N | Mute |
